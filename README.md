# 亚马逊 PDF 财务文件智能重命名助手

将亚马逊销售汇总报表、广告发票和费用发票按日期、公司及站点重命名，输出 ZIP。

## 在 Codex 桌面端安装

1. 将此仓库克隆到本地，并用 Codex 桌面端打开该仓库。
2. 重新启动桌面端，在插件目录中选择「亚马逊财务工具」来源。
3. 安装「亚马逊PDF财务文件智能重命名助手」。
4. 在新对话中附上自己的 PDF 或 ZIP，调用该插件，并提供公司简称。

处理环境需要 Python 3，并需要 `pdftotext`（Poppler）或可在该 Python 环境中导入的 `pypdf`。若使用后者，可运行 `python -m pip install pypdf`。

仓库用于分发插件。请在 Codex 对话中提供待处理文件。
